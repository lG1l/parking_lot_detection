# 04. 데이터 모델

> 🚧 미작성. 작성할 항목과 이미 정해진 관련 결정만 적어 둔다.

## 작성할 항목

- 엔티티와 필드: User, Video, AnalysisJob, Chunk, VehicleSelection, DamageInput, Candidate, CandidateClip, PinnedIncident
- 분석 상태와 전이 규칙. 아래 상태를 포함한다.
  - 대기 중 (앞에 N건): SQS에서 차례를 기다리는 중
  - 1단계 분석 중 (입력 가능): 정지 장면이 준비되어 입력할 수 있지만 1단계는 진행 중
  - 입력 완료·1단계 진행 중: 입력은 끝났고 1단계가 끝나면 2단계가 자동 시작됨
  - 2단계 분석 중 → 확인 가능 → 사건 지점 고정 / 후보 전부 확인 완료
  - 실패: 여러 번 실패해 DLQ로 옮겨진 작업
- 2단계가 두 번 시작되지 않게 하는 방법: 상태를 조건부로 바꾸기(예: "현재 상태가 X일 때만 Y로 바꾼다"). SQS 중복 전달 대비(멱등성)에도 같은 방법을 쓴다
- "앞에 N건"의 N 계산 방법 (DB에서 계산. SQS를 조회하지 않는다)
- SQS 메시지 형식 예시 (작업 ID와 작업 종류만. 예: 1단계, 2단계, 다음 묶음 비식별화)
- 원본 시간 필드 규칙 (모든 후보·클립·고정 지점이 원본 시간 기준 시작·끝을 가진다)
- 청크별 트랙 결과 파일 형식
- S3 키 구조, 원본·마스킹본·분석 결과 영역 분리 방식 (버킷 분리 또는 prefix 분리, U-05)
