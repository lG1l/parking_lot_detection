# 08. 인증·권한

> 🚧 미작성. 작성할 항목과 이미 정해진 관련 결정만 적어 둔다.

## 작성할 항목

- 관리자가 사용자 계정으로 영상을 업로드하는 방식 (PRD 4장이 설계 문서로 미룬 항목, U-14)
- 로그인 방식 (프론트와 API가 같은 출처라 쿠키·토큰 방식 모두 가능)
- 로그인 세션을 서버 메모리에 두지 않는 방법 (DB 또는 토큰). 백엔드를 여러 대로 늘릴 수 있게 하기 위해서다 (D-19)
- 원본 접근 차단 방법: API 규칙 + 백엔드 IAM 역할에 원본 영역 읽기 권한을 주지 않음 ([02장 2.9](02-architecture.md#29-aws-서비스와-권한))
- presigned URL 유효 시간 (업로드용, 재생용)
- 다운로드 기능을 제공하지 않는 방법
