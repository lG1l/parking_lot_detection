## 1. 프로젝트 개요

### 프로젝트명

개인정보 마스킹 기반 주차장 뺑소니 CCTV 후보 구간 선별 서비스

(대학교 졸업 프로젝트, 3인 진행)

### 프로젝트 목적

사용자가 합법적으로(정보주체 이외의 사람은 비식별 처리된 상태로) 주차장 CCTV 영상을 직접 확인할 수 있게 하여, 현실적인 금액으로 접근성·법적 규제·신뢰성 문제를 해결한다.

### 문제정의

**개발배경**

팀원이 몇 달 전 주차장에 주차해 둔 차량을 누군가 긁고 가는 일을 겪어 경찰에 사건을 접수했다. 이 과정에서 겪은 불편함을 계기로 주제를 선정했다.

**해결하려는 문제**

1. **접근성** — 사건을 접수하려면 경찰서에 직접 가야 한다. 일반인에게 경찰서에서 사건을 접수하는 경험은 생소하고 거부감이 든다. 접수 후 조사까지 2~3주가 걸린다.
2. **조사 범위의 불확실성** — 해당 주차장에서 긁힌 것인지 다른 곳에서 긁힌 것인지 확실하지 않고, 언제 긁혔는지도 모른다. 경찰서에 모든 주차장의 CCTV와 전체 기간을 다 접수할 수는 없다.
3. **신뢰성** — 경찰이 "못 찾았다"며 사건을 종료하면 피해자가 할 수 있는 것이 없다. 경찰이 며칠 치 CCTV를 다 봤다는 것도 믿기 어려워 의심이 남는다.
4. **비용** — KISA 문의 결과, 주차장 관리자에게 영상 열람을 신청할 권리는 있지만, 피해자가 직접 CCTV를 확인하려면 개인정보보호법에 따라 정보주체 이외의 사람을 모두 비식별 처리해야 하고 그 비용은 요청자가 전부 부담한다. 비식별화 비용은 업체마다 다르지만 매우 비싸다. (예: 피코소프트 동영상 비식별화 서비스 공개 견적 기준 `영상 1분 × 모자이크 대상 1개 × 9,000원`)

**Target User**

주차장에 주차해 둔 차량이 파손(뺑소니)되어 CCTV를 직접 확인하려는 사람 [질문 필요: 영상을 업로드하는 주체(피해자 / 주차장 관리자)와 영상을 확인하는 주체의 구분]

### 간략한 제품/서비스 설명

사용자가 주차장 CCTV 영상을 업로드하면 차량 번호판과 사람의 모습을 모자이크(비식별화) 처리하고, 사용자가 입력한 본인 차량과 파손 부위를 기준으로 접촉하는 모든 순간을 후보로 선별한다. 후보는 VLM으로 접촉 가능성이 높은 순서로 정렬되고, 사용자는 상위 후보부터 앞뒤 일정 시간 분량의 모자이크 영상을 직접 확인한다. 찾으면 해당 시간대와 비식별화 영상을 다운로드하고, 못 찾으면 다음 후보를 이어서 확인한다.

## 2. 목표

### 핵심 목표

핵심 가치 4가지: **개인정보 보호 · 직접 확인 · 후보 자동 선별 · 가능성 높은 후보순 정렬**

우선순위:

1. **합법적인 직접 확인 — 비식별화(모자이크)**: 가장 중요하다. 사용자가 합법적으로 영상을 직접 확인할 수 있어야 한다.
2. **후보 선별**: 파손 부위에 접촉하는 모든 순간을 후보군으로 선별할 수 있어야 한다.
3. **가능성 높은 후보순 정렬(VLM)**: 부가 기능이다. 높은 정확도의 접촉 판별을 기술적으로 최대한 챙기되, 가성비·현실적 측면을 고려해 타협 가능하다.

### 제공할 범위 (Scope)

- CCTV 영상 업로드 및 번호판·사람 모자이크 처리
- 사용자 차량·파손 부위 입력
- 파손 부위 접촉 순간 후보 선별
- VLM 기반 접촉 가능성 순 정렬
- 상위 후보 구간(모자이크 처리) 제공 및 추가 후보 확인
- 찾은 시간대·비식별화 영상 다운로드
- 커버 여부 미결정 [질문 필요: 아래 경우를 커버 범위로 둘지 한계점으로 남길지]
  - 원거리에서 작은 물체를 투척하는 장면
  - 굉장히 빠른 속도로 투척되는 장면
  - 파손 부위가 CCTV 상으로 보이지 않는 경우

## 4. 사용자 경험

### User Flow

1. 사용자가 CCTV 영상을 업로드한다.
2. 차량 번호판과 사람의 모습이 모자이크 처리된다.
3. 사용자가 본인 차량과 파손 부위를 입력한다.
4. 파손 부위에 접촉하는 모든 순간이 후보로 선별되고, VLM으로 접촉 가능성 순으로 정렬된다.
5. 상위 n개 후보가 각각 앞뒤 t초 분량의 모자이크 영상으로 제공된다.
6. 사용자가 영상을 직접 확인한다.
   - 찾음 → 해당 시간대와 비식별화 영상을 다운로드한다.
   - 못 찾음 → 다음 상위 m개 후보가 5번과 같이 제공된다. (후보군을 모두 보여줄 때까지 반복)

[질문 필요: 영상 확보(주차장 관리자 열람 신청) 단계가 서비스 흐름에 포함되는지 / 후보를 모두 확인하고도 못 찾은 경우의 흐름]
