# 09. KPI 평가 설계

> 🚧 미작성. 작성할 항목과 이미 정해진 관련 결정만 적어 둔다.

## 작성할 항목

- KPI 3개(비식별화 누락률, 사고 클립 후보 검출 누락률, VLM 정렬 품질)의 평가 스크립트 구조
- 데이터셋 준비, 룰 조정용·최종 측정용 클립 분할
- 추가 라벨(파손 부위 공간좌표, 비충돌 클립의 접근 쪽 면) 형식
- 결과 산출·보고 형식
- 서비스와 같은 `pipeline` 패키지를 재사용하는 방식
- 처리량 측정: KPI 평가를 돌릴 때 GPU 1대가 1시간에 처리하는 영상 시간을 함께 기록한다. "동시 N건이면 GPU M대" 계산에 쓴다 (D-20)
- 부하 테스트: Locust + 가짜 워커 시나리오, 목표 수치 N명·X초 (U-17), 결과 보고 형식 (D-20)
